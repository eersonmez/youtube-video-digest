From LLM Theory to Practical Agentic Implementations - Seth Juarez

Seth Juarez explains that while Large Language Models (LLMs) fundamentally predict the next token, their true capability as agents comes from the surrounding runtime environment. He details how simple completions evolve into structured outputs and then into complex agentic loops. Agency is not inherent in the model; it is imbued by the developer through branching logic within the harness. The discussion progresses from basic intent mapping to using tool calls for code execution, memory management via context threading, implementing guardrails, and advanced steering mechanisms like draining message queues. Ultimately, he demonstrates building a full agentic system that orchestrates multiple LLM roles—such as research and drafting—by passing state through a persistent thread.

  • LLMs are fundamentally next-token predictors; agency is provided by the runtime harness.
  • Agentic behavior emerges when the runtime uses structured outputs to trigger branching or tool execution.
  • Memory is managed by carefully injecting relevant data into the LLM's context (thread).
  • Guardrails and bindings allow developers to enforce policies on model actions within the loop.
  • Steering allows an LLM running in a loop to process external queues of messages.

Use a Rust SAT Solver to play better pickleball! - Bob McNaughton - NDC Toronto 2026

The presentation discusses the theoretical background of NP-complete problems, specifically Boolean Satisfiability (SAT), and how modern solvers can tackle these complex issues. The speaker then applies this knowledge to a practical problem: organizing a pickleball tournament with teams of three, aiming to minimize the difference in average skill level between groups. Using the SCIP library from Rust, which is designed for integer programming, the speaker models the problem by defining binary and continuous variables within a model structure. Constraints are added to ensure every player belongs to exactly one group and that each group has precisely three players. Testing with 99 players resulted in 33 groups, achieving a relatively balanced skill distribution across most teams. However, performance testing showed limitations; while it solved the problem for 99 players quickly, larger instances like 120 or 111 did not converge within reasonable timeframes.

  • Boolean Satisfiability is NP-complete and forms a basis for many complex problems.
  • Constraint Satisfaction Problems (CSPs) allow modeling real-world constraints beyond simple boolean logic.
  • The SCIP library in Rust was used to minimize skill deviation when forming balanced teams of three.
  • The optimization successfully grouped 99 players into 33 groups with minimal average skill variance.
  • Performance testing indicated that the solver struggled with larger tournament sizes.

The evolution and deprecation of traditional SSL/TLS security infrastructure.

NDC Conferences · 2026-07-31T10:35:23+00:00

Everything you learned about SSL is deprecated - Todd Gardner - NDC Toronto 2026

This talk details how the established methods of securing internet communication via SSL are fundamentally changing due to numerous vulnerabilities and advancements. The speaker traces the history from early certificate requests, noting that outdated practices like using RSA keys with 2048 bits or three-year certificates are obsolete. Major shifts include the introduction of Perfect Forward Secrecy in 2013 to counter data harvesting threats, and Certificate Transparency logs, which forced CAs to increase transparency. The traditional CA browser forum model has been challenged by automated solutions like Let's Encrypt and unilateral actions by browsers, such as Apple mandating shorter certificate lifetimes. While renewal automation is progressing, deployment across complex infrastructure remains a significant manual hurdle.

  • Traditional SSL practices are deprecated due to evolving security threats.
  • Perfect Forward Secrecy was introduced in 2013 to prevent mass decryption of recorded traffic.
  • Certificate Transparency logs forced greater accountability on Certificate Authorities (CAs).
  • Browser mandates, like Apple's, are driving the shift toward much shorter certificate lifetimes.
  • Automating certificate renewal is challenging; deployment across diverse systems remains complex.
