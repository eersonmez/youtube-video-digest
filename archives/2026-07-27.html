NDC Conferences · 2026-07-27T08:03:30+00:00

Optimizing your HttpClient usage - Nico Vermeir - NDC Copenhagen 2026

Nico Vermeir explains how to use .NET HttpClient safely and efficiently, focusing on connection reuse, error handling, configuration, handlers, and resiliency. Creating and disposing an HttpClient for every request can exhaust sockets and contribute to stale DNS behavior; a long-lived client or, preferably, IHttpClientFactory avoids this by reusing pooled connections while allowing short-lived client instances. The talk demonstrates dependency injection, named clients for centralized settings such as base addresses, and typed clients for encapsulating API calls. It recommends GetAsync when callers need to inspect status codes, with EnsureSuccessStatusCode and targeted handling of HttpRequestException for external network failures. Delegating handlers can add logging and authorization and can be chained in order. Finally, Polly policies provide retries with backoff and jitter, plus circuit breakers to reduce thundering-herd effects during outages.

  • Avoid creating and disposing HttpClient for every request because it can exhaust sockets.
  • Use IHttpClientFactory to reuse pooled connections with short-lived client instances.
  • Configure named or typed clients through dependency injection and centralize API settings.
  • Use GetAsync to inspect response status codes and handle HttpRequestException around external calls.
  • Add logging and authorization with ordered delegating handlers.
  • Use Polly retries with backoff and jitter, plus circuit breakers for transient failures and outages.
